# Public Speaking Coach Agent

An interactive AI coach that guides users to master public speaking through weekly models, script practice, and iterative feedback.

## Overview

Uses A2A Protocol, LangGraph, LiteLLM, and SAP Cloud SDK.

## Structure

- `app/main.py` - A2A server entry
- `app/agent_executor.py` - Request handling
- `app/agent.py` - Agent logic
